# Design source

Prepared on 29 October 2026 for Alireza Rajabi's GitHub profile.

- Visual reference: https://alirezarajabi.com/ — the selected Turquoise theme.
- Original wordmark: https://alirezarajabi.com/assets/wordmark-clear-vector.svg
  The SVG paths and their colors are preserved. Only the display viewport is fitted.
- Typography: Cormorant Garamond and Manrope, from the site's existing font files.
  Banner lettering is exported as vector paths; no font binaries or external font
  requests are needed to display the delivered banners.
- Palette: deep green #142c2b, cream #f7f4ee, light text #f2eee4,
  copper #dda77d and muted green #b8c9c3.
- GitHub's supported picture element:
  https://docs.github.com/en/get-started/writing-on-github/getting-started-with-writing-and-formatting-on-github/quickstart-for-writing-on-github

The introduction was approved for publication to Alireza Rajabi's GitHub profile
on 29 October 2026.
The surrounding GitHub interface and ordinary Markdown fonts remain controlled
by GitHub. Preview pages simulate README layout at desktop/mobile widths;
they are not evidence of an installed mobile app or a published profile README.
